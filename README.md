# Global Media Marketing Agency Website

This is a **simple static website** built using **HTML, CSS, and Bootstrap 5**. The project demonstrates a modern marketing agency webpage layout with a **responsive navbar**, **hero section with curved background**, **cards for different user types**, and a **“Why We?” section** highlighting features.  

The website uses **Bootstrap grid system** and **Flexbox** for layout and alignment, with interactive elements like buttons and links, gradient backgrounds, and shadow effects.

This project is useful for learning **Bootstrap layout, responsive design, Flexbox alignment, and modern hero section styling**.

## Installation

Step-by-step instructions on how to run the project locally.

1. **Clone the Repository:**  
   - Clone the project repository from GitHub:  
     ```bash
     git clone https://github.com/yourusername/global-media-website.git
     ```  
   - Or download the repository as a ZIP file and extract it.

2. **Open the Project Folder:**  
   - Open the folder using **Visual Studio Code**, **Sublime Text**, or any code editor.

3. **Run the Website:**  
   - Open the `index.html` file in your browser.  
   - You can also right-click the file and select **Open with Live Server** if using VS Code.

## Usage

Once the website is opened in a browser:

- The **navbar** contains:  
  - Logo  
  - Navigation links (Adventures, Publishers, Agencies, Company, Our Partners, Contact)  
  - Language selector dropdown  
  - Sign Up button  

- The **hero section** displays:  
  - Full-width background image with a **curved bottom border**  
  - Heading  
  - Call-to-action **gradient button**

- The **cards section** displays three cards:  
  - Advertisers, Publishers, Agencies  
  - Each card includes a title, description, **JOIN NOW button**, and **Read More link**

- The **Why We section** highlights features using icons and descriptive text, arranged using Bootstrap **grid and Flexbox**.

The website layout is **fully responsive**, ensuring content adjusts properly on mobile, tablet, and desktop screens.

## Project Structure

Key styling features include:
